The foundation beneath it

Engineering principles that make it trustworthy.

P-01

Deterministic core

Every node computes identical results — nothing can silently diverge.

P-02

Fail-hard on bad data

On inconsistency it stops and calls a human — wrong data is worse than none.

P-03

Fixed-point money

No floating point near a price — every cent is exact.

KEYSTONE

No database in the hot path

The in-memory cluster log is the source of truth — orders never wait on a disk or database round-trip. The database sits downstream, for analytics and audit only.

Happy to go deeper on the cluster on request — but the headline is simple: built for real money, not for demos.
